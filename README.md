# Strategist

**Business-First Autonomous Multi-Agent Ecosystem**

Strategist is an autonomous multi-agent development engine designed to interrogate business problems until absolute ground truth is reached, recruit and adapt specialized agent capabilities, and orchestrate cyclic verification loops (`Swarm ⇄ QA ⇄ DevOps`) to build and verify software solutions.

## Core Philosophy

> **"Do not build what is asked; uncover what is needed. Code is a liability."**

Traditional AI developer agents jump prematurely to coding a full-stack React/Node app. Strategist guards against solution bias by exploring the minimal sufficient architecture—from event-driven webhook automations and single CLI tools to decoupled multi-app constellations.

## Architecture & Verification Loops

1. **Phase 1–4 Discovery Gates**: Interrogation matrix managed by the Business Discovery Analyst.
2. **Skill Ingestion & Transpilation**: Dynamic recruitment from `alirezarezvani/claude-skills` with native Gemini transpilation.
3. **Loop A (TDD & Implementation)**: Swarm Developer ⇄ QA Adversary (adversarial tests written *before* code).
4. **Loop B (Runtime & Security)**: Swarm Developer ⇄ DevOps Auditor (linting, containerization, zero CVEs).
5. **Context Compaction**: Proactive token sliding-window management by the Context Manager.
