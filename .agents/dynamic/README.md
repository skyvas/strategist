# Dynamically Recruited Agents (.agents/dynamic/)

This directory holds persona definitions and toolsets for dynamically recruited agents generated by the **Recruiter Agent** upon approval of `docs/02_GROUND_TRUTH_SRS.md`.

## Recruited Agent Roles

### Worker Swarm
- `backend_engineer.md`: Responsible for API, domain logic, data models, and service integration.
- `frontend_engineer.md`: Responsible for user interface, responsive styling, and client state.

### Adversarial Checkers
- `qa_adversary.md`:
  - **Loop A (TDD Loop)**: Derives adversarial automated tests from `docs/03_TEST_ACCEPTANCE.md`.
  - Rejects failing implementations and records diffs into `.state/loop_audit.json`.
- `devops_auditor.md`:
  - **Loop B (Runtime & Security Loop)**: Validates containerization, linting, build pipelines, dependency security (CVEs), and secret isolation.
  - Halts promotion if security or runtime regressions occur.
